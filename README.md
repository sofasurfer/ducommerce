# Café du Commerce — HTML/CSS starter

A small, editorial French café/bar design system for a rebuild of Café du Commerce in Biel/Bienne.

## Structure

- `index.html` — starter page
- `css/style.css` — complete responsive CSS
- `images/` — put the real Café du Commerce photos here

## Image filenames

Add:
- `images/cafe-hero.jpg`
- `images/cafe-detail.jpg`

The HTML uses those filenames as placeholders.

## Design direction

- warm paper background
- wine/burgundy accent
- dark ink
- serif display typography
- monospaced utility typography
- thin rules
- rectangular buttons
- editorial layout
- minimal navigation
- no JavaScript dependency
- responsive down to mobile

## Using it in WordPress

The CSS can be moved directly into a custom theme.

Recommended structure:

`header.php`
`front-page.php`
`page-concerts.php`
`page-contact.php`
`footer.php`
`assets/css/style.css`

Keep the design system in CSS and let WordPress provide the content.
